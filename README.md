# GuessItBall

⚠️ WARNING: This game involves psychological interaction. Please read the Disclaimer before playing or contributing.

Games using emotion or psychology to engage players to interact with each other

The second game is *GuessItBall*, a game for between 2-6 people. Goal is to gain the most total yardage and/or points by the end of the game. Variants of the game without cards, and using different materials will also be posted and updated.

Players can modify the game by adding or removing rules, creating their own rules, or customizing parts to fit their own visions for the game. I will add an Anywhere variant that uses common playing cards as substitutes for the choosing the play number, and tokens for betting. There is a Bookie role to keep track of bets, tokens and the Bank.
