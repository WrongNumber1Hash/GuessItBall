# GuessItBall

⚠️ 注意：このゲームには心理的な相互作用が含まれます。プレイまたは投稿する前に免責事項をお読みください。

感情や心理学を用いてプレイヤー同士の交流を促すゲーム

2つ目のゲームは*GuessItBall*です。2～6人でプレイします。ゲーム終了時までに獲得できるヤード数とポイントの合計が最も多いゲームです。カードを使わないバージョンや、様々な素材を使ったバージョンも投稿・更新していきます。

プレイヤーはルールを追加・削除したり、独自のルールを作成したり、自分のゲームビジョンに合わせてパーツをカスタマイズしたりすることで、ゲームを変更できます。プレイナンバーの選択の代わりに一般的なトランプを使用し、賭けにはトークンを使用するAnywhereバージョンも追加します。賭け金、トークン、バンクを管理するブッキーの役割があります。
