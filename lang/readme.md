Folder for Languages
--

This is a folder for documents in other languages. Documentation will appear in both Japanese and English in the repository, but where there is only English, then we will put a Japanese language copy inside this folder. Other languages can be included if users contribute those documents and examples.

日本語 (Japanese)

言語用フォルダー

このフォルダーは他言語のドキュメントを格納するためのものです。 リポジトリ内のドキュメントは日本語と英語の両方で作成される予定ですが、英語のみしか存在しない場合は、このフォルダー内に日本語版を配置します。 ユーザーの皆様からドキュメントや例の寄稿があれば、他の言語を含めることも可能です。
